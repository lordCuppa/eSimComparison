## 📚 Documentation & Legal Requirements
**Campus SIM Guide**: Based on the provided Campus SIM_English.pdf. Includes details on packages (Plan A/B) and the application process for exchange students.

**Important Note on Phone Numbers**: Plans including a Japanese phone number (Voice) are subject to the Japanese Mobile Phone Device Identification Act. For these plans, providing a Residence Card (Zairyu Card) is mandatory.
